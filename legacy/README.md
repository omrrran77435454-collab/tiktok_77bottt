# ملفات المشروع السابق (أرشيف)

هذا المجلد يحتوي على الكود السابق لهذا المستودع (بوت تحميل من TikTok مكتوب بلغة Python).
لم يُحذف أي ملف — فقط نُقل إلى هنا حتى لا يختلط بمشروع **أدوات المعلم** الجديد في جذر المستودع.

## ⚠️ تحذير أمني مهم

الملف `legacy/main.py` يحتوي على **Telegram Bot Token مكتوب داخل الكود** (hardcoded)،
وهذا التوكن موجود أيضاً داخل **تاريخ Git** للمستودع.

المطلوب منك:

1. افتح BotFather في تيليجرام.
2. نفّذ `/revoke` للبوت القديم لإبطال التوكن المسرَّب فوراً.
3. أنشئ توكن جديداً واستخدمه فقط عبر `wrangler secret put TELEGRAM_BOT_TOKEN`.
4. لا تضع التوكن الجديد داخل أي ملف كود أو داخل Git.

إبطال التوكن هو الحل العملي الوحيد، لأن حذف الملف الآن **لا يمسح** التوكن من تاريخ Git.
