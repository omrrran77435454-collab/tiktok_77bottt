# أرشيف المشروع السابق

كان هذا المستودع يحتوي بوت تحميل من TikTok مكتوباً بلغة Python
(`main.py` و `requirements.txt`).

## ⚠️ تنبيه أمني — إجراء مطلوب منك

الملف `main.py` كان يحتوي **Telegram Bot Token مكتوباً داخل الكود**.
حُذف الملف من المستودع لأنه لا يصحّ إبقاء سرّ في شجرة الملفات،
لكن **التوكن ما زال موجوداً في تاريخ Git** ولا يمكن إزالته بالحذف وحده.

الإجراء الفعّال الوحيد:

1. افتح [@BotFather](https://t.me/BotFather) في تيليجرام.
2. نفّذ `/revoke` على البوت القديم لإبطال التوكن المسرَّب فوراً.
3. أنشئ توكناً جديداً واستخدمه **فقط** عبر `wrangler secret put TELEGRAM_BOT_TOKEN`
   أو كسرّ في GitHub Actions.
4. لا تضع التوكن الجديد في أي ملف كود أو وثيقة.

إن أردت استرجاع الكود القديم للاطّلاع، هو متاح في تاريخ Git:

```bash
git log --oneline --all -- legacy/main.py
git show <commit>:legacy/main.py
```
