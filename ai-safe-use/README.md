# الاستخدام الآمن للذكاء الاصطناعي | AI SAFE

موقع عربي توعوي (Front-End فقط) يشرح كيفية استخدام أدوات الذكاء الاصطناعي بطريقة آمنة ومسؤولة.
المشروع منجز كمشروع عملي لمقرر **تصميم الويب**.

---

## 1. وصف سريع

الموقع يقدم محتوى توعوياً مبسطاً للطلاب والمستخدمين حول:

- حماية الخصوصية والبيانات الشخصية
- التحقق من المعلومات قبل تصديقها أو نشرها
- الاستخدام الدراسي الصحيح لأدوات الذكاء الاصطناعي
- أخلاقيات الاستخدام واحترام حقوق الآخرين
- التعامل مع المحتوى المضلل واختيار الأدوات الموثوقة

الموقع بالكامل باللغة العربية وباتجاه `rtl`، ويعمل على الجوال واللوحي والكمبيوتر.

## 3. التقنيات المستخدمة

| التقنية | الإصدار | مكان الاستخدام |
|---------|---------|----------------|
| HTML5 | - | جميع الصفحات (Semantic HTML) |
| CSS3 | - | `css/style.css` و `css/responsive.css` |
| JavaScript | ES5/ES6 | `js/main.js` و `js/validation.js` و `js/ajax-modals.js` |
| Bootstrap | 5.3.3 (RTL) | القائمة الجانبية، Modal، Accordion، Grid utilities |
| jQuery | 3.7.1 | Ajax، التعامل مع العناصر، الأحداث |
| jQuery Validation | 1.21.0 | التحقق من نماذج الدخول والتسجيل والتواصل |
| Toastr | 2.1.4 | إشعارات النجاح |
| Font Awesome | 6.5.2 (Free) | جميع الأيقونات |
| WOWSlider | محرك محلي داخل `wowslider/engine1` | شريط الصور في الصفحة الرئيسية |
| خط Tajawal | SIL OFL | الخط العربي (ملفات محلية في `fonts/`) |

> جميع المكتبات موجودة **محلياً** داخل مجلد `vendor/` حتى يعمل الموقع بدون إنترنت.

### ملاحظة صريحة عن WOWSlider

بيئة تنفيذ المشروع لا تسمح بالوصول إلى موقع `wowslider.com` لتنزيل النسخة الرسمية،
لذلك تمت كتابة ملفات المحرك محلياً في `wowslider/engine1/` **بنفس بنية WOWSlider الرسمية**
(نفس أسماء الملفات والأصناف `ws_images` / `ws_active` / `ws_bullets` / `ws_caption` / `ws_next` / `ws_prev`
ونفس طريقة الاستدعاء `jQuery("#wowslider-container1").wowSlider({...})`).
تفاصيل استبدالها بمخرجات البرنامج الرسمي موجودة في `wowslider/README.txt`.

## 4. طريقة التشغيل

### مهم جداً
يجب تشغيل الموقع عبر **خادم محلي (HTTP Local Server)** وليس بفتح الملف مباشرة،
لأن **Ajax لا يعمل مع بروتوكول `file://`**.

### الخطوات

1. افتح الطرفية (Terminal / CMD) داخل مجلد المشروع `ai-safe-use`.
2. شغّل الخادم المحلي:

```bash
python -m http.server 8000
```

3. افتح المتصفح على العنوان:

```
http://localhost:8000
```

بدائل أخرى للخادم المحلي:

```bash
npx serve .
```

أو استخدام إضافة **Live Server** في محرر VS Code.

## 6. الميزات التفاعلية

- **شريط صور متحرك (WOWSlider)**: 3 شرائح مع تشغيل تلقائي، أزرار، نقاط، ودعم السحب باللمس.
- **نافذتان منبثقتان عبر Ajax**: يتم تحميل محتواهما فعلياً من `ajax/privacy-details.html` و `ajax/verification-details.html`.
- **التحقق من النماذج**: رسائل خطأ عربية واضحة في نماذج الدخول والتسجيل والتواصل.
- **إشعارات Toastr**: عند نجاح إنشاء الحساب، ونجاح نموذج التواصل، وعند اختيار موضوع في الصفحة الرئيسية.
- **قائمة جوال**: تعمل عبر Bootstrap Offcanvas.
- **تجاوب كامل**: تم اختبار الموقع من عرض 320px حتى 1920px.
