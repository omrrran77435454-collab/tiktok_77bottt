الاستخدام الآمن للذكاء الاصطناعي
مشروع مقرر تصميم الويب
=====================================

وصف المشروع
-----------
موقع عربي توعوي بسيط يشرح كيفية استخدام أدوات الذكاء الاصطناعي بطريقة آمنة ومسؤولة.
الموقع يتكون من 5 صفحات ومبني بـ HTML و CSS و JavaScript مع Bootstrap و jQuery.

صفحات الموقع
------------
1. index.html            الصفحة الرئيسية
2. html/tips.html        النصائح
3. html/privacy.html     حماية البيانات
4. html/account.html     تسجيل الدخول وإنشاء الحساب
5. html/contact.html     تواصل معنا


طريقة فتح الموقع على الهاتف (بدون إنترنت)
-----------------------------------------
1. انسخ ملف المشروع المضغوط إلى الهاتف وفك الضغط.
2. افتح مدير الملفات وادخل مجلد ai-safe-use.
3. اضغط على ملف index.html واختر فتحه بالمتصفح.

الموقع يعمل كاملاً بدون إنترنت لأن جميع المكتبات والصور والخط موجودة داخل المشروع.


طريقة فتح الموقع على الكمبيوتر
------------------------------
اضغط مرتين على ملف index.html وسيفتح في المتصفح مباشرة.


تشغيل الموقع عبر خادم محلي (لتجربة Ajax الحقيقي)
------------------------------------------------
افتح موجه الأوامر داخل مجلد المشروع ثم اكتب:

    python -m http.server 8000

ثم افتح المتصفح على العنوان:

    http://localhost:8000


ملاحظة مهمة عن Ajax
-------------------
النافذتان المنبثقتان في الصفحة الرئيسية تستخدمان jQuery Ajax لتحميل المحتوى
من مجلد ajax عند تشغيل الموقع عبر خادم (http).

أما عند فتح الموقع مباشرة من الملفات (file://) فالمتصفح يمنع Ajax لأسباب أمنية،
لذلك يوجد في ملف js/main.js محتوى احتياطي بسيط يظهر داخل النافذة نفسها،
حتى يعمل الموقع في الحالتين.


محتويات المشروع
---------------
index.html      الصفحة الرئيسية
html/           بقية الصفحات
css/            style.css للتصميم و responsive.css للتجاوب
js/             main.js وهو ملف الجافاسكربت الوحيد
images/         الرسومات بصيغة SVG
videos/         مجلد الفيديوهات
ajax/           ملفا المحتوى اللذان يتم تحميلهما عبر Ajax
vendor/         المكتبات: Bootstrap و jQuery و Validation و Toastr و Font Awesome
wowslider/      ملفات شريط الصور المتحرك
fonts/          خط Tajawal العربي
report/         تقرير المشروع بصيغة PDF


رفع المشروع على GitHub
----------------------
    git init
    git add .
    git commit -m "AI Safe Use website"
    git remote add origin <رابط المستودع>
    git branch -M main
    git push -u origin main
