منهج هذا الدليل
Learn — المفهوم شرح قصير ومثال واحد واضح. لا محاضرة.
Try — المحاولة مهمة صغيرة تكتبها بنفسك قبل أي مساعدة.
Review — المراجعة برومبت يجعل Claude يشخص محاولتك دون أن يحلها.
Fix — الإصلاح تعيد الكتابة بنفسك بناء على التشخيص.
Build — البناء مشروع مصغر يجمع ما تعلمته في شيء يعمل.

لا تطلب المساعدة قبل عشرين دقيقة

وبعد العشرين دقيقة، لا تطلب الحل. اطلب تلميحا. الفرق بينهما هو الفرق بين أن تتعلم وألا تتعلم.
ما لن يفعله هذا الدليل
لن يعطيك حلولا كاملة تنسخها. برومبتات المراجعة مصممة لمنع ذلك.
لن يشرح كل تفاصيل اللغة. يشرح ما تحتاجه لتبني، ويعلمك كيف تسأل عن الباقي.
لن يجعلك مبرمجا في أسبوع. سيعطيك منهجا تكرره حتى تصبح مبرمجا فعلا.

# مساحة تعلم البرمجة

## دورك هنا
أنت مدرب برمجة، لست منفذا. الهدف أن أتعلم أنا، لا أن يعمل الكود.

## قواعد لا تخالف
لا تكتب الحل الكامل لأي تمرين، حتى لو طلبته صراحة.
عندما أطلب مساعدة، أعطني تلميحا واحدا فقط ثم توقف وانتظر محاولتي التالية.
عندما أرسل محاولة، شخصها: ما الصحيح، وما الخطأ، ولماذا أخطأت.
اشرح سبب الخطأ لا الخطأ فقط.
لا تعدل ملفاتي مباشرة. اقترح، ودعني أكتب أنا.
إذا كان حلي صحيحا لكن يمكن تحسينه، قل ما الأفضل ولماذا، ولا تعد كتابته.

## أسلوب الشرح
بالعربية الواضحة، والمصطلح الإنجليزي عند الحاجة.
مثال واحد قصير خير من شرح طويل.
انته دائما بسؤال يدفعني للخطوة التالية.

def process(path):
    with open(path) as f:
        lines = f.readlines()
    cleaned = [l.strip() for l in lines if l.strip()]
    total = sum(len(l) for l in cleaned)
    print("Lines:", len(cleaned))
    print("Chars:", total)
    with open("report.txt", "w") as f:
        f.write(str(total))
    return cleaned

        return int(text)
    except:
        return 0


def read_age_better(text):
    try:
        value = int(text)
    except ValueError:
        raise ValueError("Age must be a whole number, got: " + repr(text))
    if not 0 <= value <= 130:
        raise ValueError("Age out of range: " + str(value))
    return value

import json
import urllib.request
import urllib.error

def fetch(url, timeout=10):
    try:
        with urllib.request.urlopen(url, timeout=timeout) as response:
            if response.status != 200:
                raise RuntimeError("Unexpected status: " + str(response.status))
            return json.loads(response.read().decode("utf-8"))
    except urllib.error.HTTPError as e:
        raise RuntimeError("HTTP error " + str(e.code)) from e
    except urllib.error.URLError as e:
        raise RuntimeError("Network error") from e
    except json.JSONDecodeError as e:
        raise RuntimeError("Response was not valid JSON") from e

import sqlite3

conn = sqlite3.connect("school.db")
cur = conn.cursor()

cur.execute('''
    CREATE TABLE IF NOT EXISTS students (
        id INTEGER PRIMARY KEY,
        name TEXT NOT NULL,
        grade INTEGER CHECK (grade BETWEEN 0 AND 100)
    )
''')

cur.execute("INSERT INTO students (name, grade) VALUES (?, ?)", ("Sara", 92))
conn.commit()

for row in cur.execute("SELECT name, grade FROM students WHERE grade > ?", (80,)):
    print(row)

conn.close()

الاختبارات
الاختبار ليس عبئا إضافيا. هو ما يسمح لك بتغيير الكود دون خوف، وهو أوضح توثيق لما يفترض أن يفعله.
اختبار الوحدة
الاختبار الجيد يصف سلوكا واحدا، ويفشل لسبب واحد، ويقرأ اسمه فيفهم القارئ ما الذي انكسر دون فتح الكود.

التصحيح المنهجي
المبرمج المبتدئ يغير أشياء حتى يختفي الخطأ. المبرمج المحترف يضع فرضية ويختبرها.
من الخطأ إلى السبب في خمس خطوات
التغيير العشوائي قد يخفي الخطأ ولا يزيله، فيعود لاحقا في مكان أسوأ. المنهج يوصلك إلى السبب لا إلى اختفاء العرض.

الخطأ الأول: الأسرار في الكود
المفتاح المكتوب داخل الكود يصل إلى Git، ومن Git إلى كل من نسخ المستودع، وإلى الأبد حتى لو حذفته في commit لاحق.

الخطأ الثاني: الثقة في المدخلات
أي شيء يأتي من خارج برنامجك غير موثوق: إدخال المستخدم، والملف، ورد الواجهة البرمجية. تحقق منه قبل استخدامه، ولا تدمجه في استعلام أو أمر نظام.
الفرق الذي يمنع حقن SQL
# never do this
cur.execute("SELECT * FROM users WHERE name = '" + name + "'")

# always do this
cur.execute("SELECT * FROM users WHERE name = ?", (name,))
الخطأ الثالث: رسائل خطأ تكشف الداخل
رسالة الخطأ التي تعرض مسار الملف على الخادم أو نص الاستعلام تساعد المهاجم أكثر مما تساعد المستخدم. اعرض رسالة مفهومة، وسجل التفاصيل في السجل لا على الشاشة.
الكود النظيف في خمس قواعد
اسم يشرح نفسه أفضل من تعليق يشرح اسما سيئا.
دالة واحدة لمسؤولية واحدة، وطولها يقرأ بلا تمرير الشاشة.
لا تكرر نفسك، لكن لا تجرد قبل أن يتكرر الشيء ثلاث مرات.
التعليق يشرح لماذا لا ماذا. ماذا يقولها الكود نفسه.
احذف الكود الميت. Git يحتفظ به إن احتجته.

ما يغطيه: الملفات والوحدات والاختبارات وهياكل البيانات.
المطلوب: يقرأ مجلدا من الملفات النصية ويخرج تقريرا: عدد الكلمات، وأكثر الكلمات تكرارا، ومتوسط طول الجملة.
